# 📚 Study Tracker

A modern AI-assisted Study Tracker web application that helps students organize their learning journey, monitor study progress, and stay productive.

> ⚡ Built in under **5 minutes** using Generative AI during an AI Competition to demonstrate rapid application development and prompt engineering capabilities.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yamini-elite/study-tracker.git
```

Move into the project

```bash
cd study-tracker
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
